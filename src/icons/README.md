# Icons Directory

This directory should contain the QuadTV extension icons in the following sizes:

- icon-16.png (16x16 pixels)
- icon-32.png (32x32 pixels)
- icon-48.png (48x48 pixels)
- icon-96.png (96x96 pixels)

The icons should follow Firefox extension guidelines and represent the QuadTV brand.

For development, you can create placeholder icons or design proper ones that reflect the multi-view grid concept.
